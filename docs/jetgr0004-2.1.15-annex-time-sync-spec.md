## 時刻同期機能 仕様

| | |
|---|---|
| 装置名称 | 出力制御ユニット（○○○○） |
| 型式 | ○○○○-○○ |

| 会社名 | ○○○○株式会社 |

### 1. 適用範囲

本紙は、出力制御機能付 PCS 等を構成する出力制御ユニット（以下「本装置」という）の
時刻同期機能の仕様を定める。

### 2. 時刻同期方式

本装置は NTP クライアント（RFC 5905、SNTP 単発問い合わせ）を実装し、上位サーバの
時刻情報に自動同期する。運用開始後に時刻を手動設定する機能は有しない。

### 3. 同期先

出力制御スケジュールサーバ（電力サーバまたは配信事業者サーバ）が提供する NTP サーバ
機能に同期する。接続先アドレスは一般送配電事業者が定める伝送仕様書の指定に従う。
同期先が複数アドレスを応答する場合は、応答の得られたアドレスを使用する。

### 4. 同期契機

| 契機 | 内容 |
|------|------|
| 装置起動時 | 起動処理の一環として時刻同期を実行する |
| 定期 | 起動後は 1 時間周期で自動実行する |
| スケジュール取得時 | 出力制御スケジュール取得処理に併せて実行する |

### 5. 同期に要する時間

**同期処理の開始から 60 秒以内に同期を完了する。**

ここでいう同期処理の開始とは上位サーバへの最初の問い合わせ送出時点をいい、完了とは
本装置の内部時計が上位サーバ時刻に対し第 6 項の精度に収まった時点をいう。

### 6. 同期後の時刻精度

同期完了後の本装置の内部時計は、上位サーバ時刻に対し **±1 秒以内** とする。

### 7. 内部時計の精度および保持

| 項目 | 仕様 |
|------|------|
| 内部時計の精度 | ±60 秒以内／月（常温） |
| 停電時の保持 | バックアップ電源により内部時計を保持し、停電により消失しない |
| 定期補正 | 固定スケジュール更新（年 1 回以上）時に時刻を補正し、上記精度を維持する |

### 8. 時刻改ざん対策

運用開始後の手動による時刻調整機能を有しない。初期設定時を除き、時刻の設定は第 2 項の
自動同期のみによる。

### 9. 時計消失時の動作

内部時計が年月日を含めて消失した場合は、時刻同期の完了または保守作業による再設定が
完了するまで、発電設備の運転を停止する。

### 10. 同期失敗時の動作

同期に失敗した場合は 60 秒間隔で再試行し、失敗事象をログに記録する。再試行中は
第 9 項に準じ、有効な時刻が確定するまで出力制御スケジュールの適用を行わない。

### 11. ログ記録内容

時刻同期の実行ごとに、以下を装置ログに記録する。

- 同期処理の開始時刻および完了時刻
- 同期に要した時間
- 同期前および同期後の、上位サーバ時刻に対する時刻偏差
- 同期先サーバのアドレス
- 同期の成否（失敗時はその理由）
