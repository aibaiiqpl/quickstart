### 1. 適用範囲

本書は、出力制御機能付 PCS 等を構成する出力制御ユニット（以下「本装置」という）の
時刻管理機能について、その方式および仕様値を定める。

### 2. 時刻管理機能の構成

本装置の時刻管理機能は、以下の 4 つの要素から構成される。

| 要素 | 本書での規定箇所 |
|------|------------------|
| 上位時刻サーバとの時刻同期 | 第 3 章 |
| 内部時計（精度・停電時の保持） | 第 4 章 |
| 時刻情報消失時の動作 | 第 5 章 |
| ログ記録 | 第 6 章 |

なお、保守作業時の取扱いは保守手引書に定めるものとし、本書の規定範囲に含まない。

### 3. 時刻同期

#### 3.1 同期方式

本装置は NTP クライアント（RFC 5905）を実装し、上位時刻サーバの時刻情報に自動同期する。
時刻同期方法は Step モードとする。運用開始後における本装置の時刻設定は、本章に定める
上位時刻サーバとの自動同期によって行う。

#### 3.2 同期先

一般送配電事業者が定める伝送仕様書において指定される時刻サーバ（NTP サーバ）に同期する。
接続先の FQDN およびポートは同伝送仕様書の指定に従う。名前解決の結果が複数アドレスと
なる場合は、応答の得られたアドレスを使用する。

#### 3.3 同期契機

伝送仕様書に定める同期タイミングに従う。

| 契機 | 実施時間帯 |
|------|------------|
| 初回通信 ID 認証前（機器交換時を含む） | 任意 |
| 電源起動時 | 任意 |
| 定期更新（最大 1 回／日） | 時刻サーバへの負荷分散のため、発電所 ID 末尾のチェックサムに応じて伝送仕様書が割り当てる時間帯に実施する |
| その他手動更新（エラーリトライ等） | 任意 |

#### 3.4 同期に要する時間

**同期処理の開始から 60 秒以内に同期を完了する。**

- 同期処理の開始とは、上位時刻サーバへの最初の問い合わせを送出した時点をいう。
- 同期の完了とは、本装置の内部時計が上位時刻サーバ時刻に対し第 3.5 項の精度に収まった
  時点をいう。
- 上記は上位時刻サーバから応答が得られる場合の値である。応答が得られない場合は
  第 3.6 項のリトライを行う。

#### 3.5 同期後の時刻精度

同期完了後の本装置の内部時計は、上位時刻サーバ時刻に対し **±1 秒以内** とする。

#### 3.6 同期失敗時のリトライ

伝送仕様書に定めるリトライ条件に従い、同期エラー時は 1 分間隔で最大 5 回まで再試行する。
さらにエラーとなった場合は 30 分後に再リトライを継続する。失敗事象はいずれも第 7 章の
とおりログに記録する。

### 4. 内部時計

#### 4.1 精度

内部時計に使用するクロック部品の周波数偏差は **±3 ppm（年）以下** とする。これは
月あたりの時計誤差 ±60 秒以内（31 日換算で ±22.4 ppm 以下）の要件を満足する。

#### 4.2 停電時の保持

停電時はバックアップ電源により内部時計の計時を継続し、内部時計が消失しない仕様とする。
**300 秒以上の停電後に復電した場合においても、基準時刻に対する内部時計の偏差は
±15 秒以内** とする。

#### 4.3 定期補正

固定スケジュール更新（年 1 回以上）時に時刻を補正し、第 4.1 項の精度を維持する。

### 5. 時刻情報消失時の動作

本装置は内部時計の時刻情報の消失（年月日を含む喪失）を検出した場合、発電設備の運転を
停止する。

| 項目 | 仕様 |
|------|------|
| 検出時の動作 | 出力制御値を 0% とし、発電設備の運転を停止する |
| 出力低下までの時間 | 時刻情報消失の検出から **300 秒以内** に出力を 5% 以下とする |
| 復帰条件 | 第 3 章の時刻同期が完了し、有効な時刻が確定するまで運転を再開しない |
| スケジュールの扱い | 有効な時刻が確定するまで出力制御スケジュールを適用しない |

### 6. ログ記録

時刻管理に関する事象について、以下を装置ログに記録する。

| 事象 | 記録内容 |
|------|----------|
| 時刻同期の実行 | 同期処理の開始時刻、完了時刻、同期に要した時間、同期前および同期後の上位時刻サーバ時刻に対する偏差、同期先サーバのアドレス、成否 |
| 同期の失敗 | 失敗の理由、リトライ回数、次回リトライ予定 |
| 時刻情報の消失検出 | 検出時刻、実施した停止動作、出力が 5% 以下となった時刻 |
| 停電および復電 | 停電検出時刻、復電時刻、復電後の時刻偏差 |

### 7. 対応する試験項目

本書の各規定と JETGR0004-1-2.1 の試験項目との対応は以下のとおり。

| 試験項目 | 本書の規定箇所 |
|----------|----------------|
| 2.1.12 停電時時計機能保持確認試験 | 第 4.2 項（300 秒以上の停電後も ±15 秒以内） |
| 2.1.13 時刻情報消失時運転停止確認試験 | 第 5 章（300 秒以内に出力 5% 以下） |
| 2.1.14 内蔵時計精度確認試験 | 第 4.1 項（±3 ppm／年、±60 秒/月を満足） |
| **2.1.15 時計同期確認試験** | **第 3.4 項（同期に要する時間 60 秒以内）**、第 3.1〜3.3 項、第 3.5 項 |
