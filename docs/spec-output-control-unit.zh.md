## 全量買取用出力制御装置 技術仕様书

| | |
|---|---|
| 製品名 | 全量買取用出力制御装置（全量买取用输出控制装置） |
| 製品形式 | **EW-PRC 2000** |
| 制造者 | EcoWatt |
| 软件版数 | **Ver. 1.00** |
| 本文制定日 | 2026 年 1 月 18 日 |
| 本文版数 | 1.0 |

本装置是本公司提供的出力制御软件与通用硬件平台（第 2.2 项）组合而成的产品。本文规定的
功能和规格值是上述软件版数下的规格。

### 1. 适用范围

本文规定构成「出力制御機能付 PCS 等」的全量買取用出力制御装置 EW-PRC 2000（以下称
"本装置"）的技术规格。本装置适用于全量买取方式的发电设备。

本装置从一般送配電事業者的调度信息配信系统取得出力制御调度，向狭义 PCS 下发输出控制
指令，从而使发电输出按照出力制御调度受控。

### 2. 装置构成

#### 2.1 构成

| 区分 | 内容 |
|------|------|
| 本装置 | 全量買取用出力制御装置 EW-PRC 2000（本文对象） |
| 上位装置 | 一般送配電事業者的调度服务器及时刻服务器 |
| 下位装置 | 狭义 PCS（NR 制 PCS-9567TU 系列 等） |
| 站内时刻同步设备 | GPS 同步 NTP 服务器（第 2.3 项，由本公司在发电所站内设置并供给） |

本文中，将本装置与狭义 PCS 组合后的整体称为"广义 PCS"。输出控制相关功能在本装置与
狭义 PCS 之间的分担如下。

| 功能 | 分担 |
|------|------|
| 输出控制调度的取得・保持 | 本装置 |
| 时刻同步・内部时钟管理 | 本装置 |
| 基于输出变化时间的过渡控制（见 3.2） | **本装置** |
| 按输出控制指令值［kW］控制实际输出 | 狭义 PCS |

### 3. 输出控制功能

#### 3.1 输出控制值

| 项目 | 规格 |
|------|------|
| 设定范围 | 0～100 %（相对合同容量的比率） |
| 分辨率 | 1 % |
| 基准 | 合同容量（见 3.3） |

#### 3.2 输出变化时间

输出控制指令值变化时，使实际输出变化到目标值的过渡时间（以下称"输出变化时间"）可以
设定。**基于输出变化时间的过渡控制由本装置执行。** 本装置按输出变化时间逐时计算输出
控制指令值，仅将计算结果下发给狭义 PCS（见 4.2）。不会向狭义 PCS 设定输出变化时间
本身。

| 项目 | 规格 |
|------|------|
| 设定范围 | **300～600 秒（5～10 分钟）** |
| 设定分辨率 | **1 分钟（60 秒）** |
| 默认值 | **300 秒（5 分钟）** |
| 设定途径 | 本装置的设定画面，或 Modbus TCP 寄存器（见 4.3，寄存器 15006） |

最大受电电力（合同容量）100 %→0 % 及 0 %→100 % 的输出变化时间，可在 5～10 分范围内
按 1 分为单位设定（300 秒＝5 分、360 秒＝6 分、…、600 秒＝10 分）。实际设定值依据与
一般送配电事业者的协商结果决定。

（参考）本装置的设定接口在实现上以秒为单位接收数值，寄存器上的可输入范围为 1～3600 秒。
作为出力制御機能付 PCS 等运用时的设定范围如上表所示。

##### 3.2.1 输出变化的控制方式

| 控制方式 | 内容 | 控制阶梯 |
|----------|------|----------|
| **线性控制（默认）** | 从变化开始时的输出到目标值，以输出变化时间对应的恒定变化率（线性）连续变化 | ― |
| 斜坡控制（阶梯控制） | 以一定阶梯呈阶梯状变化 | 每阶梯 ≤10 %。阶梯间隔＝输出变化时间÷10（限制在 30～60 秒）。输出变化时间 5 分时为 10 %／30 秒，10 分时为 10 %／60 秒 |
| 实时控制 | 不设过渡时间，立即变化到目标值 | ― |

控制方式通过本装置的设定画面，或 Modbus TCP 寄存器（见 4.3，寄存器 15005）选择。
默认为线性控制。

#### 3.3 合同容量

| 项目 | 规格 |
|------|------|
| 设定范围 | 大于 0 且不超过 5,000 kW |
| 用途 | 输出控制值（%）的基准值。输出控制指令值［kW］＝输出控制值［%］× 合同容量［kW］ |
| 设定途径 | 本装置的设定画面，或 Modbus TCP 寄存器（见 4.3） |

#### 3.4 未取得输出控制调度时的动作

未持有有效的出力制御调度时所适用的输出控制值可以设定。

| 项目 | 规格 |
|------|------|
| 设定范围 | 0～100 % |
| 默认值 | **0 %** |

### 4. 通信

#### 4.1 上位通信（调度服务器）

| 项目 | 规格 |
|------|------|
| 方式 | HTTPS（由本装置发起会话。不接受外部发起的会话） |
| 协议与数据格式 | 遵循一般送配電事業者制定的伝送仕様書的指定 |
| 取得对象 | 固定调度、更新调度 |
| 取得周期 | 遵循更新调度中指定的下次访问日期时间。无指定时按设定值（默认 30 分钟） |
| 取得周期设定范围 | 1 秒～86,400 秒（24 小时） |

#### 4.2 下位通信（狭义 PCS）

| 项目 | 规格 |
|------|------|
| 方式 | Modbus TCP（本装置为客户端，狭义 PCS 侧为服务端） |
| 本装置向狭义 PCS 写入 | 输出控制指令值［kW］（32 位，2 个寄存器）、运行/停止指令 |
| 本装置从狭义 PCS 读出 | 实际输出［kW］、累计电量、PCS 故障状态 |
| 本通信不传递的信息 | 输出变化时间、输出控制调度（均在本装置内部处理） |

基于输出变化时间的过渡控制按上述 3.2 由本装置执行，本装置仅将逐时计算出的输出控制
指令值［kW］写入狭义 PCS。因此，狭义 PCS 侧无需具备设定输出变化时间的功能。

#### 4.3 外部监视・设定接口（Modbus TCP 服务端）

本装置面向外部监视装置、聚合商提供 Modbus TCP 服务端功能。主要寄存器如下。

| 寄存器 | 内容 | 备注 |
|--------|------|------|
| 15003 / 15004 | 合同容量［kW］写入（高位字／低位字，u32） | 写低位字时反映 |
| 15005 | 控制模式写入 | |
| **15006** | **输出变化时间［秒］写入** | 可输入范围 1～3600。运用设定范围见 3.2，为 300～600（5～10 分、1 分单位） |
| 15007 | 未取得调度时的默认输出［%］写入 | 0～100 |
| 15008 | PCS 指令（1: 停止、2: 启动） | 脉冲点，写入后复位为 0 |
| 15102 / 15103 | 合同容量［kW］读出（高位字／低位字） | |
| 15104 | 控制模式读出 | |
| **15105** | **输出变化时间［秒］读出** | |
| 15106 | 未取得调度时的默认输出［%］读出 | |
| 15303 ～ | 当日的出力制御调度（30 分钟单位 48 点） | |
| 15351 ～ | 次日的出力制御调度（30 分钟单位 48 点） | |

#### 4.4 ECHONET 输出控制命令

**本装置不具备 ECHONET／ECHONET Lite 输出控制命令功能。** 输出控制仅通过上述 4.1 的
调度取得和 4.2 的向狭义 PCS 写入输出控制指令值来实现。

本装置与狭义 PCS 之间的通信如上述 4.2 所述为 Modbus TCP，不使用 ECHONET Lite 输出
控制命令。因此，由本装置与狭义 PCS 构成的广义 PCS 整体不具备 ECHONET 输出控制命令
功能。

### 5. 时刻管理

#### 5.1 时刻同步

##### 5.1.1 同步方式

本装置实现 NTP 客户端（RFC 5905），自动同步到上位时刻服务器的时刻信息。同步方法为
**Step 模式**。运行开始后本装置的时刻设定，通过本项规定的与上位时刻服务器的自动同步
进行。

##### 5.1.2 同步对象

本装置以下述 2 个系统为时刻同步对象，优先使用主系统。

| 系统 | 同步对象 | 备注 |
|------|----------|------|
| **主** | 一般送配電事業者制定的伝送仕様書中所指定的时刻服务器（NTP 服务器） | 接続先的 FQDN 和端口遵循该伝送仕様書的指定 |
| 副 | 站内 GPS 同步 NTP 服务器（第 2.3 项） | 主系统无响应时使用。以 GPS 提供的日本标准时为时刻源的 stratum 1 服务器 |

主系统名称解析结果为多个地址时，使用其中有响应的地址。

副系统是为了在与主系统无法建立通信的情况下也维持与日本标准时的同步而采取的冗余措施。
无论从哪个系统完成同步，均满足 5.1.4 的所需时间和 5.1.5 的时刻精度。

##### 5.1.3 同步触发

本装置在以下触发条件下执行时刻同步。

| 触发 | 内容 |
|------|------|
| 首次通信 ID 认证前 | 在发电所 ID 的登录确认之前执行（含设备更换时）|
| 电源启动时 | 作为启动处理的一环执行 |
| 定期同步 | 启动后定期自动执行 |
| 重试 | 按 5.1.6 的条件执行 |

定期同步的实施周期和实施时间段，按一般送配電事業者制定的伝送仕様書的规定进行设定。

##### 5.1.4 同步所需时间

**自同步处理开始起 15 秒以内完成同步。**

- "同步处理开始"指向上位时刻服务器发出首次问询的时点。
- "同步完成"指本装置内部时钟相对上位时刻服务器时刻进入 5.1.5 精度范围内的时点。
- 上述为能从上位时刻服务器得到响应时的值。得不到响应时按 5.1.6 进行重试。

##### 5.1.5 同步后的时刻精度

同步完成后本装置的内部时钟，相对上位时刻服务器时刻在 **±1 秒以内**。

##### 5.1.6 同步失败时的重试

主系统无响应时，本装置进行重试。重试的间隔和次数按一般送配電事業者制定的伝送仕様書的
规定进行设定。规定次数的重试后仍未完成同步时，切换到 5.1.2 的副系统。

同步失败事件均按第 6 章记录到日志。

#### 5.2 内部时钟

##### 5.2.1 精度

内部时钟所用时钟元件的频率偏差为 **±3 ppm（年）以下**。这满足每月时钟误差 ±60 秒以内
（31 天换算为 ±22.4 ppm 以下）的要求。

##### 5.2.2 停电时的保持

内部时钟（RTC）由可更换纽扣电池（CR2032 系／BR2032 系）备份，在本装置电源被切断的
状态下仍继续计时。采用停电不会导致内部时钟丢失的设计。

**即使在 300 秒以上的停电后复电的情况下，内部时钟相对基准时刻的偏差也在 ±15 秒以内。**

因备份电池耗尽等原因导致内部时钟的时刻信息丢失时，按 5.3 规定动作。

##### 5.2.3 定期校正

在固定调度更新（每年至少 1 次）时校正时刻，维持 5.2.1 的精度。

#### 5.3 时刻信息丢失时的动作

本装置检测到内部时钟的时刻信息丢失（含年月日的丢失）时，停止发电设备的运行。

| 项目 | 规格 |
|------|------|
| 检出时的动作 | 将输出控制值设为 0 %，停止发电设备运行 |
| 输出降低所需时间 | 自检出时刻信息丢失起 **300 秒以内**使输出降至 5 % 以下 |
| 恢复条件 | 在 5.1 的时刻同步完成、有效时刻确定之前不重新开始运行 |
| 调度的处理 | 在有效时刻确定之前不适用出力制御调度 |

### 6. 日志记录

本装置将以下事件记录到装置日志。

| 区分 | 记录内容 |
|------|----------|
| 时刻同步的执行 | 同步处理的开始时刻、完成时刻、同步所需时间、同步前及同步后相对上位时刻服务器时刻的偏差、同步对象服务器地址、成败 |
| 时刻同步的失败 | 失败原因、重试次数、下次重试预定 |
| 时刻信息丢失的检出 | 检出时刻、实施的停止动作、输出降至 5 % 以下的时刻 |
| 停电及复电 | 停电检出时刻、复电时刻、复电后的时刻偏差 |
| 调度取得 | 取得日期时间、取得种别（固定／更新）、取得先 URL、发电所 ID、成败、失败时的重试结果 |
| 输出控制的执行 | 适用的输出控制值、适用时刻、向狭义 PCS 下发的指令内容 |
| 设定变更 | 变更项目、变更前后的值、操作者 |
