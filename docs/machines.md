# 机器清单

## 跳板机

```bash
ssh -p 6041 wudun@aiwatt.net
```

通过该跳板机可访问 `192.168.110.*` 网段的内网机器。

> 使用约定：连内网机器前先直接 `ping` 目标地址，能 ping 通就直连，ping 不通再走跳板机。
