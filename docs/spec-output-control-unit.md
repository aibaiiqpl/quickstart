### 1. 適用範囲

本書は、出力制御機能付 PCS 等を構成する全量買取用出力制御装置 EW-PRC 2000
（以下「本装置」という）の技術仕様を定める。本装置は全量買取方式の発電設備に適用する。

本装置は、一般送配電事業者のスケジュール情報配信システムから出力制御スケジュールを
取得し、狭義 PCS に対して出力制御指令を与えることにより、発電出力を出力制御スケジュール
に従って制御する。

### 3. 出力制御機能

#### 3.1 出力制御値

| 項目 | 仕様 |
|------|------|
| 設定範囲 | 0〜100 %（契約容量に対する比率） |
| 分解能 | 1 % |
| 基準 | 契約容量（下記 3.3） |

#### 3.2 出力変化時間

出力制御指令値が変化した際、実出力を目標値まで変化させる過渡時間（以下「出力変化時間」
という）を設定できる。**出力変化時間に基づく過渡制御は本装置が行う。** 本装置は出力変化
時間に従って時々刻々の出力制御指令値を演算し、その演算結果のみを狭義 PCS へ与える
（下記 4.2）。狭義 PCS に対して出力変化時間そのものを設定することはない。

| 項目 | 仕様 |
|------|------|
| 設定範囲 | **300〜600 秒（5〜10 分）** |
| 設定分解能 | **1 分（60 秒）** |
| 既定値 | **300 秒（5 分）** |
| 設定手段 | 本装置の設定画面、または Modbus TCP レジスタ（下記 4.3、レジスタ 15006） |

最大受電電力（契約容量）の 100 %→0 % および 0 %→100 % までの出力変化時間を、
5〜10 分の範囲で 1 分単位に設定することができる（300 秒＝5 分、360 秒＝6 分、…、
600 秒＝10 分）。実際の設定値は一般送配電事業者との協議結果に基づき決定する。

（参考）本装置の設定インタフェースは秒単位で値を受け付ける実装であり、レジスタ上の
入力可能範囲は 1〜3600 秒である。出力制御機能付 PCS 等としての運用における設定範囲は
上表のとおりとする。

##### 3.2.1 出力変化の制御方式

| 制御方式 | 内容 | 制御ステップ |
|----------|------|--------------|
| **線形制御（既定）** | 変化開始時の出力から目標値まで、出力変化時間で一定の変化率（リニア）となるよう連続的に変化させる | ― |
| ランプ制御 | 一定のステップで階段状に変化させる | 1 ステップあたり 10 % 以下。ステップ間隔＝出力変化時間÷10（30〜60 秒の範囲に制限）。出力変化時間 5 分のとき 10 %／30 秒、10 分のとき 10 %／60 秒 |
| 即時制御 | 過渡時間を設けず目標値へ直ちに変化させる | ― |

制御方式は本装置の設定画面、または Modbus TCP レジスタ（下記 4.3、レジスタ 15005）に
より選択する。既定は線形制御である。

#### 3.3 契約容量

| 項目 | 仕様 |
|------|------|
| 設定範囲 | 0 を超え 1,000,000,000 kW 以下 |
| 用途 | 出力制御値（%）の基準値。出力制御指令値［kW］＝出力制御値［%］× 契約容量［kW］ |
| 設定手段 | 本装置の設定画面、または Modbus TCP レジスタ（下記 4.3） |

#### 3.4 出力制御スケジュール未取得時の動作

有効な出力制御スケジュールを保持していない場合に適用する出力制御値を設定できる。

| 項目 | 仕様 |
|------|------|
| 設定範囲 | 0〜100 % |
| 既定値 | **0 %** |

### 4. 通信

#### 4.1 上位通信（スケジュールサーバ）

| 項目 | 仕様 |
|------|------|
| 方式 | HTTPS（本装置からセッションを開始する。外部からのセッション開始は受け付けない） |
| プロトコル・データ形式 | 一般送配電事業者が定める伝送仕様書の指定に従う |
| 取得対象 | 固定スケジュール、更新スケジュール |
| 取得周期 | 更新スケジュールで指定された次回アクセス日時に従う。指定が無い場合は設定値（既定 30 分）による |
| 取得周期の設定範囲 | 1 秒〜86,400 秒（24 時間） |

#### 4.2 下位通信（狭義 PCS）

| 項目 | 仕様 |
|------|------|
| 方式 | Modbus TCP（本装置がクライアント、狭義 PCS 側がサーバ） |
| 本装置から狭義 PCS への書き込み | 出力制御指令値［kW］（32 ビット、2 レジスタ）、運転・停止指令 |
| 本装置が狭義 PCS から読み出す情報 | 実出力［kW］、積算電力量、PCS 故障状態 |
| 本通信で授受しない情報 | 出力変化時間、出力制御スケジュール（いずれも本装置の内部で処理する） |

出力変化時間に基づく過渡制御は上記 3.2 のとおり本装置が実施し、本装置は演算した時々刻々
の出力制御指令値［kW］のみを狭義 PCS へ書き込む。このため、狭義 PCS 側に出力変化時間を
設定する機能は必要としない。

#### 4.3 外部監視・設定インタフェース（Modbus TCP サーバ）

本装置は外部の監視装置・アグリゲータ向けに Modbus TCP サーバ機能を備える。主要な
レジスタは以下のとおり。

| レジスタ | 内容 | 備考 |
|----------|------|------|
| 15003 / 15004 | 契約容量［kW］書き込み（上位語／下位語、u32） | 下位語の書き込みで反映 |
| 15005 | 制御モード書き込み | |
| **15006** | **出力変化時間［秒］書き込み** | 入力可能範囲 1〜3600。運用設定範囲は 3.2 のとおり 300〜600（5〜10 分、1 分単位） |
| 15007 | スケジュール未取得時の既定出力［%］書き込み | 0〜100 |
| 15008 | PCS 指令（1: 停止、2: 起動） | パルス点。書き込み後 0 に復帰 |
| 15102 / 15103 | 契約容量［kW］読み出し（上位語／下位語） | |
| 15104 | 制御モード読み出し | |
| **15105** | **出力変化時間［秒］読み出し** | |
| 15106 | スケジュール未取得時の既定出力［%］読み出し | |
| 15303 〜 | 当日の出力制御スケジュール（30 分単位 48 点） | |
| 15351 〜 | 翌日の出力制御スケジュール（30 分単位 48 点） | |

#### 4.4 エコーネット出力制御コマンド

**本装置はエコーネット（ECHONET／ECHONET Lite）出力制御コマンド機能を有しない。**
出力制御は上記 4.1 の出力制御スケジュールの取得、および 4.2 の狭義 PCS への出力制御指令値
の書き込みによってのみ行う。

本装置と狭義 PCS との間の通信は上記 4.2 のとおり Modbus TCP であり、ECHONET Lite に
よる出力制御コマンドは使用しない。したがって、本装置と狭義 PCS とで構成する広義 PCS
（第 2.1 項）は、全体としてエコーネット出力制御コマンド機能を有しない。

### 5. 時刻管理

#### 5.1 時刻同期

##### 5.1.1 同期方式

本装置は NTP クライアント（RFC 5905）を実装し、上位時刻サーバの時刻情報に自動同期する。
時刻同期方法は Step モードとする。運用開始後における本装置の時刻設定は、本項に定める
上位時刻サーバとの自動同期によって行う。

##### 5.1.2 同期先

本装置は以下の 2 系統を時刻同期先とし、主系統を優先して使用する。

| 系統 | 同期先 | 備考 |
|------|--------|------|
| **主** | 一般送配電事業者が定める伝送仕様書において指定される時刻サーバ（NTP サーバ） | 接続先の FQDN およびポートは同伝送仕様書の指定に従う |
| 副 | 構内 GPS 同期 NTP サーバ（第 2.3 項） | 主系統から応答が得られない場合に使用する。GPS による日本標準時を時刻源とする stratum 1 サーバである |

主系統の名前解決の結果が複数アドレスとなる場合は、応答の得られたアドレスを使用する。

副系統は、主系統との通信が確立できない場合においても日本標準時との同期を維持するための
冗長化措置である。いずれの系統から同期した場合も、5.1.4 の所要時間および 5.1.5 の時刻
精度を満足する。

##### 5.1.3 同期契機

本装置は以下の契機で時刻同期を実行する。

| 契機 | 内容 |
|------|------|
| 初回通信 ID 認証前 | 発電所 ID の登録確認に先立って実行する（機器交換時を含む） |
| 電源起動時 | 起動処理の一環として実行する |
| 定期同期 | 起動後は定期的に自動実行する |
| 再試行 | 5.1.6 の条件により実行する |

定期同期の実施周期および実施時間帯は、一般送配電事業者が定める伝送仕様書の規定に
従って設定する。

##### 5.1.4 同期に要する時間

**同期処理の開始から 60 秒以内に同期を完了する。**

- 同期処理の開始とは、上位時刻サーバへの最初の問い合わせを送出した時点をいう。
- 同期の完了とは、本装置の内部時計が上位時刻サーバ時刻に対し 5.1.5 の精度に収まった
  時点をいう。
- 上記は上位時刻サーバから応答が得られる場合の値である。応答が得られない場合は
  5.1.6 のリトライを行う。

##### 5.1.5 同期後の時刻精度

同期完了後の本装置の内部時計は、上位時刻サーバ時刻に対し **±1 秒以内** とする。

##### 5.1.6 同期失敗時のリトライ

主系統からの応答が得られない場合、本装置は再試行を行う。再試行の間隔および回数は、
一般送配電事業者が定める伝送仕様書の規定に従って設定する。規定回数の再試行後も同期が
完了しない場合は、5.1.2 の副系統へ切り替える。

同期の失敗事象はいずれも第 6 章のとおりログに記録する。

#### 5.2 内部時計

##### 5.2.1 精度

内部時計に使用するクロック部品の周波数偏差は **±3 ppm（年）以下** とする。これは
月あたりの時計誤差 ±60 秒以内（31 日換算で ±22.4 ppm 以下）の要件を満足する。

##### 5.2.2 停電時の保持

内部時計（RTC）は交換可能なコイン型電池（CR2032 系／BR2032 系）によりバックアップされ、
本装置の電源が遮断された状態においても計時を継続する。停電により内部時計が消失しない
仕様とする。

**300 秒以上の停電後に復電した場合においても、基準時刻に対する内部時計の偏差は
±15 秒以内** とする。

バックアップ電池の消耗等により内部時計の時刻情報が消失した場合は、5.3 に定める動作と
なる。

##### 5.2.3 定期補正

固定スケジュール更新（年 1 回以上）時に時刻を補正し、5.2.1 の精度を維持する。

#### 5.3 時刻情報消失時の動作

本装置は内部時計の時刻情報の消失（年月日を含む喪失）を検出した場合、発電設備の運転を
停止する。

| 項目 | 仕様 |
|------|------|
| 検出時の動作 | 出力制御値を 0 % とし、発電設備の運転を停止する |
| 出力低下までの時間 | 時刻情報消失の検出から **300 秒以内** に出力を 5 % 以下とする |
| 復帰条件 | 5.1 の時刻同期が完了し、有効な時刻が確定するまで運転を再開しない |
| スケジュールの扱い | 有効な時刻が確定するまで出力制御スケジュールを適用しない |

### 6. ログ記録

本装置は以下の事象を装置ログに記録する。

| 区分 | 記録内容 |
|------|----------|
| 時刻同期の実行 | 同期処理の開始時刻、完了時刻、同期に要した時間、同期前および同期後の上位時刻サーバ時刻に対する偏差、同期先サーバのアドレス、成否 |
